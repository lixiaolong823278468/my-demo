# 日前电价预测系统使用文档

## 1. 系统概览

当前系统已经实现以下能力：

- 未来 96 点日前出清价格预测
- 分时段建模
- XGBoost 直接预测日前出清价格 + 相似法参考曲线
- 自定义历史训练时间范围
- 手动重训
- 保留当前模型、上一版模型、历史训练日志与指标
- 预测 Excel 自动回填 `预测价格`
- 真正前后端分离：`HTML / JS / CSS` 独立前端 + `Python API` 后端
- Windows 桌面入口保留

## 3. 数据要求

### 3.1 历史数据

- 存放在 `D:\每日工作\代码示例\预测程序-------\demo1\数据\`
- 按年存放，例如：
  - `D:\每日工作\代码示例\预测程序-------\demo1\数据\2025年`
  - `D:\每日工作\代码示例\预测程序-------\demo1\数据\2026年`
- 每个 Excel 文件中：
  - 每个 Sheet 表示一天
  - 第 1 行为字段名
  - 第 2 ~ 97 行为 96 个 15 分钟时段

### 3.2 预测文件

默认预测文件为：

- `D:\每日工作\代码示例\预测程序-------\demo1\预测文件\预测文件.xlsx`

当前模板支持按列头中的日期自动识别：

- 最新日期作为预测日
- 预测只使用预测日供需、日期类型和火电开机容量等当天特征
- 参考日数据仅用于生成相似法参考曲线，不作为昨日同点价格特征
- 如果模板里包含预测日前一日的价格，例如预测 `5.4` 时模板中有 `5.3` 价格，则相似法优先使用模板里的 `5.3`
- 当参考天数为 `N` 且模板参考日可用时，系统再从历史数据中补齐最近的 `N-1` 天
- 预测结果自动写回 `预测价格` 列

## 4. 如何启动与使用

### 4.1 进入目录

```bash
cd /d D:\每日工作\代码示例\预测程序-------\demo1
```

### 4.2 启动网页版

推荐直接双击：

```bash
launch_web.bat
```

或命令行启动：

```bash
python api_server.py --open-browser
```

启动后浏览器会打开：

- `http://127.0.0.1:8000`

网页中可直接：

- 选择训练起止日期
- 点击 `手动重训模型`
- 查看当前模型、上一版模型和历史版本
- 直接编辑预测文件表格
- 点击 `执行预测`
- 实时查看运行状态、进度条、日志和预测曲线

### 4.3 命令行训练模型

全量训练：

```bash
python dayahead_timeseg_model.py train
```

默认按最近 `60` 天训练，并把最后 `14` 天作为验证集：

```bash
python dayahead_timeseg_model.py train --training-window-days 60 --valid-days 14
```

手动指定起始日期：

```bash
python dayahead_timeseg_model.py train --start-date 2025-01-01
```

只用 `2026-02-01` 到 `2026-03-31`：

```bash
python dayahead_timeseg_model.py train --start-date 2026-02-01 --end-date 2026-03-31
```

指定验证集和训练轮数：

```bash
python dayahead_timeseg_model.py train --valid-days 14 --num-boost-round 500
```

训练模型不再使用参考日/昨日同点价格特征，只保留直接价格预测模型。

相似法参考权重不属于训练参数，训练中心不再配置这些权重。

### 4.4 命令行执行预测

```bash
python dayahead_timeseg_model.py predict --forecast-file ".\预测文件\预测文件.xlsx"
```

执行后会：

- 输出结果到 `D:\每日工作\代码示例\预测程序-------\demo1\output\dayahead_price_prediction.xlsx`
- 自动回填 `预测文件.xlsx` 中的 `预测价格` 列

### 4.5 查看训练日志

```bash
python dayahead_timeseg_model.py runs
```

### 4.6 回退到上一版模型

```bash
python dayahead_timeseg_model.py rollback
```

## 6. API 后端说明

后端入口：

- `D:\每日工作\代码示例\预测程序-------\demo1\api_server.py`

主要接口包括：

- `GET /api/config`：读取基础路径与价格上下限

- `POST /api/train`：启动后台训练任务
- `POST /api/window-optimization/run`：手动启动训练窗口自动寻优任务
- `POST /api/predict`：启动后台预测任务
- `POST /api/model/activate`：切换默认模型
- `POST /api/model/rollback`：回退到上一版模型
- `POST /api/model/delete`：批量删除历史模型
- `GET /download/output`：下载最新预测结果文件

## 7. 模型版本管理

系统自动保留：

- `models\current`：当前默认模型
- `models\previous`：上一版模型
- `models\history\run_xxx`：每次正式训练后的历史模型
- `models\training_runs.jsonl`：每次训练日志

当前网页版版本列表只展示正式训练版本：

- 会展示 `run_...` 版本
- 不会把 `rollback_backup_...` 这种内部回退备份混入正式版本列表

同时保留以下规则：

- 最新模型默认作为默认模型
- 回退到旧模型时，当前模型仍会保留为上一版
- 默认模型和上一版模型受保护，不能直接删除

## 9. 训练窗口与历史时间范围

默认训练方式是滚动窗口：

- 训练页面分为 `自动训练窗口寻优` 和 `手动训练模型` 两块，避免寻优参数和手动训练参数混用
- 网页版默认 `按最近 N 天训练`
- `训练窗口天数` 默认 `60`
- `验证集天数` 默认 `14`
- 系统自动使用历史最新日期之前的最近 `60 + 14` 天：前 60 天训练，后 14 天验证

也支持通过以下方式手动控制训练范围：

- 网页版训练模式切换为 `手动起止日期`
- 命令行使用 `--start-date`
- 命令行使用 `--end-date`
- 命令行使用 `--training-window-days`

典型用法：

- 日常重训：使用默认最近 60 天
- 阶段复盘：手动指定某一段市场机制更接近当前的近期数据
- 参数试验：对比 30 / 60 / 90 / 120 / 180 / 365 天窗口

这在电力现货建模里很重要，因为：

- 过早的数据可能与当前市场规律不一致
- 历史跨度过长有时会降低当前阶段预测效果

### 9.1 手动训练窗口寻优

训练窗口寻优不再由程序启动或运行状态刷新自动触发。系统只保留寻优状态和历史数据签名记录；如果新增或修改了历史 Excel 数据，需要在训练页面手动点击 `自动寻优并训练最优模型` 按钮启动寻优和最优模型训练。

手动寻优逻辑：

- 页面可配置 `寻优最大历史天数`，默认 `100` 天
- 寻优区单独配置 `寻优验证集天数`、`寻优 XGBoost 轮数`、`局部细搜半径`
- 先粗搜候选窗口：`30 / 45 / 60 / 75 / 90 / 120 / 150 / 180 / 240 / 365`，并额外加入当前最大可搜索历史天数
- 如果最大可搜索历史天数不足 `30` 天，则只测 `1` 天和最大可搜索历史天数
- 找到粗搜最优窗口后，再围绕它前后 `15` 天逐日细搜
- 每个候选窗口都使用同一个验证集天数，默认 `14` 天
- 评分直接使用主预测模型指标，综合 `MAE + 0.2 * RMSE` 选择最优窗口
- 选出最优窗口后，会用该窗口重新训练正式模型，并自动启用为当前默认模型

寻优状态会写入 `models\window_optimization.json`，包括历史数据签名、最优窗口、候选窗口指标、最终启用模型等信息。临时回测模型保存在 `output\window_optimization\`，用于复盘不同窗口的效果。

页面中的 `自动寻优并训练最优模型` 按钮是唯一触发入口；普通启动和状态刷新不会自动寻优或自动重训。

## 10. 当前预测方法说明

当前主模型直接用 XGBoost 预测 `日前出清价格`。相似法不再参与训练，也不再作为模型输入特征，只在预测结果中额外生成一条参考曲线，方便和当前业务相似法结果对比。

### 10.0 价格区间分类预测

系统在具体价格预测模型之外，新增一套独立的价格区间分类模型：

- 价格模型继续输出 `模型预测价格`，用于查看 96 点价格曲线。
- 区间模型单独训练，输出 `最可能价格区间`、`区间概率`、`高价概率` 和 `区间历史命中率`。
- 默认区间为 `<250`、`250-300`、`300-400`、`400-600`、`600-1000`、`>1000`。
- 区间配置位于训练中心的 `价格区间概率模型训练配置` 区块，保存后会写入 `models/training_preferences.json`。
- 修改区间边界会改变历史标签，因此需要重新训练模型后才会影响预测。
- 预测页将价格曲线、区间色带和明细表放在一起展示，方便同时判断价格水平和高价风险。

### 10.1 训练链路

训练时按页面或命令行选择的起始日期、结束日期过滤历史样本，然后清理 `日前出清价格 / 火电空间 / 必要特征` 缺失的行。系统会按 5 个时段分别训练一套 `no_lag_96` 直接价格模型。

模型的训练目标是：

```text
模型预测值 = 日前出清价格
```

训练特征中不包含 `similar_price`、`similar_gap`，也不训练“相似法残差”。

### 10.2 预测链路

预测时系统会先读取当前模型的 `metadata.json`：

- 统一使用 `no_lag_96` 主模型，不再按预测文件是否包含参考日价格切换模型变体
- 主模型直接输出 `predicted_price`，页面展示为 `模型预测价格`
- 同时再单独运行一版相似法，输出 `similar_price` 作为参考曲线
- `model_similarity_diff` 表示 `模型预测价格 - 相似法参考价格`，只是对比差值，不是训练残差

```text
模型预测价格 = XGBoost 直接预测日前出清价格
```

### 10.3 相似法权重逻辑

相似法权重用于控制“什么样的历史时段算更相似”。当前支持 5 个权重：

- `thermal_space`：火电空间权重，内部计算为 `用电负荷 - 新能源出力`
- `renewable_power`：新能源出力权重
- `thermal_on_capacity`：火电容量权重
- `day_type`：日期类型权重
- `thermal_space_load_ratio`：供需比权重，内部计算为 `火电空间 / 用电负荷`

这组权重在不同链路中的含义如下：

- 训练链路：权重不参与主模型训练，主模型只学习直接预测 `日前出清价格`。
- 预测偏好：预测中心单独保存一份权重偏好，用于下次打开页面时显示默认值。
- 元数据：旧模型中可能保留训练时记录的权重，仅用于兼容命令行未显式传权重的场景。
- 预测链路：网页预测时使用预测中心当前权重，重新计算预测日的相似法参考曲线。
- 缓存：直接价格训练特征缓存不依赖相似法权重，修改权重不会影响主模型训练特征缓存。

简单理解：权重只影响 `相似法参考价格`，不影响 XGBoost 主模型如何训练、也不参与模型预测价格的加减计算。

预测页面会单独维护一份页面偏好：

- 偏好文件位置：`models\training_preferences.json`
- 用途：只决定预测页面下次默认显示什么相似法参考权重
- 保存时机：在网页预测页面修改权重后会自动保存；点击 `执行预测` 时也会再次保存当前页面权重
- 独立性：训练模型、切换默认模型、回退模型、删除历史模型都不会覆盖预测页面偏好
- 与模型元数据区别：`training_preferences.json` 是预测页面默认值，`metadata.json` 是某个模型自身保存的训练元信息

### 10.4 参考日价格口径

系统不再把参考日/昨日同一时段价格作为模型输入特征。每天价格按当天供需、日期类型、火电开机容量等实际条件预测；参考日只服务于相似法参考曲线和页面对比展示。

预测模板中的参考日优先级最高。例如预测 `5.4` 时，如果模板里有 `5.3` 的供需和日前出清价格，系统会先把模板中的 `5.3` 放入相似法参考池；若页面参考天数设置为 `3`，再从历史数据中寻找最近的另外 `2` 天补齐。这样即使历史数据目录里还没有 `5.3`，相似法也能使用模板提供的最新参考日。

## 11. 价格边界约束

山西省日前电价预测结果统一限制在：

```text
0 ~ 1500 元/兆瓦时
```

该约束已经写入核心预测链路：

- 网页预测
- 命令行预测
- Excel 回填
- 导出文件

都会保持一致。

## 12. XGBoost 参数详细说明

当前默认参数为：

```python
eta = 0.05
max_depth = 5
min_child_weight = 3
subsample = 0.85
colsample_bytree = 0.85
num_boost_round = 400
```

### 12.1 `eta`

也叫学习率。

作用：

- 控制每一轮树对结果的修正幅度

影响：

- 越小：学习更慢、更稳，不容易过拟合，但通常要更多轮数
- 越大：学习更快，但更容易波动和过拟合

调参建议：

- 如果验证集误差波动大，可以适当降低
- 如果模型明显欠拟合，可以适当提高

### 12.2 `max_depth`

单棵树最大深度。

作用：

- 控制模型复杂度

影响：

- 越大：能学习更复杂关系，但更容易过拟合
- 越小：泛化更稳，但可能欠拟合

调参建议：

- 若模型对尖峰电价抓不住，可尝试略增
- 若训练很好、验证变差，可尝试略减

### 12.3 `min_child_weight`

叶子节点继续分裂所需的最小样本权重。

作用：

- 控制树是否容易继续细分

影响：

- 越大：更保守，不容易过拟合
- 越小：更容易学习细节，也更容易吃噪声

调参建议：

- 数据波动噪声大时可适当增大
- 需要捕捉更细的尖峰时可适当减小

### 12.4 `subsample`

每轮训练抽取样本比例。

作用：

- 控制样本采样强度

影响：

- 越小：随机性更强，抗过拟合更好，但可能不稳定
- 越大：更充分利用数据，但可能过拟合

调参建议：

- 若训练集很好而验证集一般，可适当降低

### 12.5 `colsample_bytree`

每棵树抽取特征比例。

作用：

- 控制特征采样强度

影响：

- 越小：模型更保守，更抗过拟合
- 越大：更充分使用全部特征

调参建议：

- 特征之间相关性高时，可适当降低

### 12.6 `num_boost_round`

总训练轮数。

作用：

- 控制树的总数量

影响：

- 太少：容易欠拟合
- 太多：训练时间增加，也可能过拟合

调参建议：

- 配合 `eta` 一起看
- `eta` 低时通常需要更高轮数
