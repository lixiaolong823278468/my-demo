# Excel 数据异常记录与展示设计

## 目标

在训练和预测读取 Excel 数据时记录数据质量问题，并在前端提供独立“数据异常”页面用于查看问题汇总和明细。

## 行为规则

- 训练：历史数据中存在异常天或异常 Sheet 时跳过该天/Sheet，继续使用其余有效数据训练。
- 预测：预测文件中关键字段异常时停止预测；历史数据中的异常 Sheet 仍按训练逻辑跳过。
- 展示：所有发现的问题都保存为报告，前端可以查看最近报告、报告列表、统计与明细。
- 不自动修复：本版本不修改 Excel 原文件。

## 异常范围

- Sheet 日期无法识别。
- 有效时点不足 96 行。
- 必要字段缺失或字段名不匹配。
- 必要数值字段为空或无法转为数字。
- 预测模板无法识别预测日、参考日或关键字段。

## 报告结构

报告保存到 `output/data_quality_reports/`，每个任务生成一个 JSON 文件。报告包含：

- `report_id`：报告编号。
- `task_type`：`train` 或 `predict`。
- `status`：`clean`、`completed_with_issues`、`blocked`。
- `summary`：总问题数、错误数、警告数、跳过 Sheet 数、拦截问题数。
- `issues`：明细项，包含文件、Sheet、日期、时点、字段、原值、异常类型、严重级别、处理结果。
