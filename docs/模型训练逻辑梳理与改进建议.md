> 分析日期：2026-05-24
> 核心文件：dayahead_core.py（~5200行）、dayahead_timeseg_model.py、price_interval.py

---

## 一、项目概况

本项目为**日前电力市场出清价格预测系统**，使用梯度提升树模型（XGBoost / LightGBM / CatBoost）对次日96个时段的电价进行预测。系统支持：

- 分时段独立建模
- 多模型后端自动选优
- 相似法参考日辅助预测
- 高价概率调整
- 滚动回测验证
- 模型版本管理与回滚

## 三、训练流程详解

### 3.1 数据加载与预处理

1. **数据源**：从 `数据/` 目录读取按月组织的 Excel 文件，每个 Sheet 对应一天，含96个时段（15分钟粒度）
2. **核心字段提取**：
   - 总加电力值(MW) → `total_load`
   - 风光电力值(MW) → `renewable_power`
   - `net_load = total_load - renewable_power`（即火电空间/剩余负荷）
   - 日前出清价格(元/MWh) → 训练目标
   - 火电开机容量 → 从"日前出清概况"文本中正则提取
3. **缓存策略**：基于文件签名（大小 + 修改时间 + SHA256 hash）的智能缓存，避免重复解析
4. **质量校验**：`validate_history_sheet()` 和 `validate_forecast_template()` 对缺失字段、异常值进行检测

### 3.2 特征工程

| 特征类别 | 具体特征 | 说明 |
|---------|---------|------|
| 负荷类 | total_load, net_load, renewable_power, thermal_space_load_ratio | 当日负荷曲线特征 |
| 时间类 | hour, period, weekday, month, is_weekend, is_holiday | 时间编码 |
| 容量类 | thermal_on_capacity | 火电开机容量(MW) |
| 滞后类 | price_lag_1/2/3/7d, price_ma_3/7d, price_std_7d, net_load_lag_1d | 历史价格和负荷滞后 |
| 相似性类 | knn_similar_price, weighted_knn_regression_price, similar_count, similar_distance | 多因子KNN最近邻 |

**两种特征变体**：
- `no_lag_96`：不含滞后特征（基础11维特征）
- `with_lag_96`：含滞后特征（11 + 7 + 1 = 19维特征）

### 3.3 分时段训练

将96个时段按时间分为 5~6 段（可自定义，最多8段），每段独立训练模型：

- **默认分段**：
  - night: 00:00 - 06:00（时段1~24）
  - morning_peak: 06:00 - 10:00（时段25~40）
  - midday: 10:00 - 15:00（时段41~60）
  - evening_peak: 15:00 - 20:00（时段61~80）
  - late_night: 20:00 - 24:00（时段81~96）

- **训练过程**：每段对所有 `feature_variant × model_backend` 组合进行训练
- **选优逻辑**：自动按综合评分选出每段最佳模型

### 3.4 模型选择机制

```python
score = MAE + 0.2 × RMSE  # 综合评分（MAE为主，兼顾极端误差）
```

- 全局最优模型：`selected_model_key`
- 逐时段最优模型：`selected_segment_price_models`（允许不同时段使用不同后端/特征组合）

### 3.5 辅助模型

1. **价格区间分类模型** (`price_interval.py`)：
   - 预测价格落入各区间的概率
   - 用于计算 `high_price_probability` / `extreme_price_probability`
   - 支持多后端训练

2. **火电开机容量预测模型**：
   - 日级模型，基于负荷统计特征预测次日火电开机容量
   - 支持 XGBoost / Ridge 等后端
   - 预测值作为价格模型的输入特征

### 3.6 预测流程

1. 加载训练好的分时段模型（从 `models/current/` 目录）
2. 解析预测文件（次日负荷/风光预测值）
3. 构建参考日（最近N天 / 同类型日）→ 计算相似性特征
4. 逐时段预测基础价格
5. 叠加概率调整：
   - 高价概率上调（当高价概率超阈值时）
   - 场景相似性调整（新能源高占比场景向下修正）
6. 输出 Excel 结果并回填预测模板

## 五、改进建议

### 🔴 高优先级（P0）

#### 1. segment_5（18:00-22:00 晚高峰）模型精度严重不足

**问题**：segment_5 的 MAE=68.6、RMSE=143.2，是表现最好时段（segment_6=29.5）的 2.3 倍。最大单点误差达 1145 元/MWh，RMSE/MAE=2.09 说明存在大量极端误差。

**建议**：

- **增加专用特征**：
  - 前一时段价格差分（捕捉日内趋势）
  - 跨时段价格梯度（前几个时段的价格变化率）
  - 电网调峰约束指标（抽蓄调用情况、联络线潮流）
  - 同时段历史波动率指标（过去7天同时段价格标准差）

- **模型结构调整**：
  - 为高波动时段使用更深的树（`max_depth=7~8` 而非统一的5）
  - 引入分位数回归（Quantile Regression），输出价格区间而非仅点估计
  - 考虑对高波动时段引入 LSTM/Transformer 等序列模型作为补充

- **数据增强**：
  - 对历史极端价格事件进行分析，提取触发条件作为特征
  - 引入 SMOTE 或类似方法增强高价样本

#### 2. 系统性低估偏差需要修正

**问题**：全局 bias=-19.2，高价区间 bias=-151.2，所有时段均存在低估。高价时 under_rate=81.3%。

**建议**：

- **引入偏差校正层**：训练完成后，对验证集残差按时段/价格区间计算均值偏差，预测时加回
- **不对称损失函数**：使用自定义 XGBoost 目标函数，对低估施加更大惩罚：
  ```python
  def asymmetric_loss(y_pred, dtrain):
      y_true = dtrain.get_label()
      residual = y_pred - y_true
      # 低估惩罚更大（alpha > 0.5）
      grad = np.where(residual < 0, -2 * alpha * residual, -2 * (1-alpha) * residual)
      hess = np.where(residual < 0, 2 * alpha, 2 * (1-alpha))
      return grad, hess
  ```
- **高价概率调整增强**：当前 `high_price_recall=0%`，价格区间模型无法识别高价。需要：
  - 降低高价触发阈值
  - 增加高价样本在区间分类模型中的权重
  - 考虑专门训练一个二分类模型（是否高价）替代多分类

#### 3. 火电开机容量模型需要重建

**问题**：MAE=1320 MW 几乎无预测价值。训练样本仅96天、验证集10天，数据极度稀疏。

**建议**：

- **短期**：如果火电开机容量变化不大，直接使用前一天实际值（naive forecast）可能比模型更好
- **中期**：增加历史数据量，至少需要半年以上的日级样本
- **评估该特征的实际贡献**：对比移除 `thermal_on_capacity` 特征前后的模型表现，如果贡献为负则暂时移除

#### 4. 添加关键外部特征

**当前缺少的重要特征**：

| 特征 | 来源 | 对价格的影响 |
|------|------|-------------|
| 气温（最高/最低/平均） | 气象数据 | 强烈影响空调负荷 |
| 天气类型（晴/阴/雨） | 气象数据 | 影响光伏出力 |
| 风速预测 | 气象数据 | 影响风电出力 |
| 煤价/气价 | 市场数据 | 影响火电报价成本 |
| 输电断面约束 | 调度数据 | 影响区域供需平衡 |
| 联络线送受电计划 | 调度数据 | 影响省内供需 |

**实施建议**：优先接入气温数据（获取成本低、影响大），可先通过日均温度分档处理。

### 🟡 中优先级（P1）

#### 4. 模型集成策略优化

**当前方式**：按评分选"单一最优"模型（虽然支持逐时段选优，但本质仍是选一）。

**改进方向**：

```python
# 当前：选最优
final_price = best_model.predict(features)

# 建议：加权集成
weights = softmax(-scores / temperature)  # scores越低权重越高
final_price = sum(w * model.predict(features) for w, model in zip(weights, models))
```

- 使用 **Stacking**：将多模型预测值作为二层模型（如线性回归）的输入
- 或使用 **加权平均**：权重按验证集表现的倒数确定
- 按价格区间动态调整权重（如：低价时 XGBoost 好，高价时 CatBoost 好）

#### 5. 高价样本权重策略精细化

**当前**：超过 80 分位的样本统一乘以 2.0 权重。

**改进**：

```python
# 当前：阶梯式
weight = 2.0 if price > quantile_80 else 1.0

# 建议：连续递增式
weight = 1.0 + alpha * max(0, price - threshold) / (PRICE_CAP - threshold)

# 或 Focal Loss 思路
weight = 1.0 + beta * |prediction_error|^gamma  # 对难样本自适应加权
```

- 对不同时段设置不同的高价阈值（晚高峰 600 元可能才算高价，夜间 300 元就算高价）
- 可引入"方向性加权"：预测偏低比偏高的惩罚更大（对储能调度更关键）

#### 6. KNN 相似法增强

**当前**：仅基于 net_load 的欧氏距离进行 KNN 匹配。

**改进**：

- **加入时间衰减权重**：`weight = exp(-lambda * days_diff)` 越近的参考日权重越高
- **多维度相似性度量**：
  - net_load 形态相似性（DTW 距离或余弦相似度）
  - 日类型匹配（工作日vs节假日）
  - 季节/月份匹配
  - 天气条件相似性
- **自适应 K 值**：根据匹配质量动态调整K（距离大时增大K取平均，距离小时减小K取精确值）

#### 7. 滚动回测效率优化

**问题**：`rolling_backtest_selected_model()` 对每个测试日重新训练完整模型，计算开销极大。

**改进**：

- 利用 XGBoost 增量学习：`xgb_model` 参数实现在已有模型基础上继续训练
- 使用 `process_type='update'` 在已有树上更新叶子值
- 或采用 **Expanding Window** 而非逐日重训（每周重训一次）

**建议**：

- 引入 Optuna 进行贝叶斯超参优化：
